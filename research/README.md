# Research

This directory contains work that goes beyond simple paper reproduction —
genuine investigation, not just re-implementation.

## Research progression

```
Reimplement
  ↓
Reproduce
  ↓
Modify
  ↓
Experiment
  ↓
Find something interesting
  ↓
Form a hypothesis
  ↓
Run controlled experiments
  ↓
Publish
```

## Rules

- Nothing here is labeled "research" unless it goes beyond following an
  existing paper's method on the paper's own terms.
- Every project records a research question and hypothesis before results.
- Negative/failed results are recorded, not hidden.
