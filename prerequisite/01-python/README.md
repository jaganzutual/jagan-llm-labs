# Stage 1 — Python Basics

You don't need to become a Python wizard. Just comfortable enough
to read PyTorch code and small experiments.

## Must-know before Paper #1

- [ ] Variables
- [ ] Functions (def, args, return)
- [ ] Classes / OOP (class, __init__, self, methods)
- [ ] Lists, dictionaries, sets, tuples
- [ ] List comprehensions
- [ ] Iterators / generators (basic idea)
- [ ] Exceptions (try / except)
- [ ] Modules / packages (import, __init__.py)
- [ ] pip
- [ ] Virtual environments (venv)
- [ ] Type hints (basic, e.g. `def f(x: int) -> int`)
- [ ] File I/O (open, read, write)
- [ ] Basic debugging (print, reading tracebacks)

## Concrete practice

Write tiny scripts:
1. swap two numbers in a list
2. dict of word -> id
3. class with `__init__` + one method
4. read a text file, count unique words

## After this stage

You should be able to read `rnn_cell.py` and `rnn_unrolled.py`
without confusion.

## Done when

Write all 4 practice scripts without looking anything up, and:
- explain what `self` does in a class
- explain the difference between a list and a dict in one sentence
- read `rnn_cell.py` line by line out loud with no confusion
